# 🧠 SorobanMind — أكاديمية السوروبان

تطبيق تعليمي تفاعلي لتعلّم **السوروبان الياباني** والحساب الذهني للأطفال (5-12 سنة)، مبني بـ React + TypeScript + Tailwind CSS.

---

## 📌 نظرة عامة

**SorobanMind** منصة تعليمية عربية بالكامل (RTL) تُعلّم الأطفال:
- أساسيات العداد الياباني (الخرزات، العارضة، الأعمدة).
- رياضيات الأصابع قبل السوروبان.
- الجمع والطرح المباشر (بدون قواعد).
- قواعد **متممات الخمسة** (الجدة 5 — Small Friends).
- قواعد **مكملات العشرة** (عملاق العشرات 10 — Big Friends).
- **القاعدة المركبة** (دمج الجدة 5 والعملاق 10).
- **تحدي السلاسل الطويلة** (3 إلى 10 عمليات).
- **الحساب الذهني التخيلي** (Anzan).

---

## ✨ الميزات الرئيسية

### 🎯 1. اختيار الدور (Role Selection)
- **البطل (Hero)** — للطفل، يبدأ رحلة التعلم.
- **ولي الأمر (Guardian)** — لمتابعة تقدم الطفل.

### 🎓 2. التعلّم (Learn) — 10 مستويات تفاعلية

**المنهاج الحالي:**

- **المستوى 0**: ✋ رياضيات الأصابع (مقدمة قبل السوروبان).
- **المستوى 1**: 🏰 تعريف بالسوروبان (ما هو، تاريخه، فوائده).
- **المستوى 2**: 🔢 تمثيل الأعداد على السوروبان (0 - 9999).
- **المستوى 3**: ➕ العمليات المباشرة (من اليسار إلى اليمين).
- **المستوى 4**: 👵 متممات الخمسة — جمع (+1 = +5 − 4).
- **المستوى 5**: 👵 متممات الخمسة — طرح (−1 = −5 + 4).
- **المستوى 6**: 💪 مكملات العشرة — جمع (+1 = +10 − 9).
- **المستوى 7**: 💪 مكملات العشرة — طرح (−1 = −10 + 9).
- **المستوى 8**: ✨ الاندماج السحري (العمليات المركبة).
- **المستوى 9**: 🏇 تحدي السلاسل الطويلة (3-10 عمليات).

**مميزات كل مستوى:**
- **جدول القاعدة** (يُعرض للطفل بشكل مرئي).
- **قصة تعليمية صوتية** ("الجدة 5"، "العملاق 10"، "قلعة السوروبان").
- **وضعان لكل درس**:
  - **"شاهد"** — عرض توضيحي للخطوات مع المعداد.
  - **"جرّب"** — الطفل يحرّك الخرزات بحرية للوصول إلى القيمة.
- **10 محاولات** قبل إظهار زر "أرني الإجابة".
- **زر "مسح"** لإعادة تعيين المعداد بدون فقدان الحركة.
- **حفظ التقدم تلقائياً** في `localStorage`.
- **نظام فتح تدريجي**: المستوى التالي يُفتح **فقط** بعد إتمام **جميع** أمثلة "جرّب" في المستوى الحالي.
- **شريط تقدم** لكل مستوى يُظهر عدد الأمثلة المحلولة.
- **مكافأة**: 30 XP عند إتمام كل مستوى.

### 🏆 3. الامتحان النهائي (Final Exam) — 25 سؤالاً / 100 درجة

**يُفتح فقط بعد إتمام جميع المستويات (0-9).**

- **بنك أسئلة**: 100 سؤال متنوع.
- **اختيار عشوائي**: 25 سؤالاً في كل امتحان.
- **4 نقاط** لكل سؤال (المجموع 100).
- **درجة النجاح**: 60/100.
- **4 أسئلة بأرقام منزلتين** (من الـ 25).
- **أنواع الأسئلة**:
  - 3 عمليات (30 سؤالاً).
  - 4 عمليات (40 سؤالاً).
  - 5 عمليات (30 سؤالاً).
- **الميزات**:
  - **لا تظهر الإجابات** أثناء الامتحان.
  - **المعداد التفاعلي** لتمثيل الناتج.
  - **زر "تخطي"** يظهر بعد 5 محاولات.
  - **حفظ النتيجة** في `localStorage`.
  - **إعادة المحاولة** متاحة بلا حدود.

### 💪 4. التدريب (Practice)

- **أسئلة متعددة** (جمع + طرح).
- **فلترة ذكية حسب الدرس**.
- **المعداد التفاعلي**.
- **تغذية راجعة فورية** مع Confetti.
- **نظام النقاط**: 15 XP لكل إجابة صحيحة.

### 👁️ 5. التصور الذهني (Anzan Flash)

- **5 مستويات متدرجة**:
  - 🌱 **مبتدئ** — عمليات مباشرة (آحاد ≤ 9).
  - ⭐ **متوسط** — يستخدم الجدة 5.
  - 🔥 **متقدم** — يستخدم عملاق 10.
  - 💎 **خبير** — عمليات مركبة.
  - 👑 **محترف** — منزلتان + سلاسل.
- **عرض الأرقام** بالتسلسل مع الإشارة (+ أو −).
- **اللون**: أخضر للجمع، أحمر للطرح.
- **المجموع الحالي** يظهر أسفل كل عملية.

### 🎯 6. المهام (Quests)
- **9 مهام متنوعة**.
- **مكافآت XP** تصل إلى 150 لكل مهمة.
- **تتبع التقدم** تلقائياً.

### 👨‍👩‍👧 7. لوحة ولي الأمر (Guardian Dashboard)
- **عرض XP الطفل**.
- **أيام الحضور المتتالية**.
- **المستوى الحالي**.
- **إحصائيات شاملة**.
