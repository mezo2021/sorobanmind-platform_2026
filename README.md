## 🚨 المشاكل الحالية (قيد الحل)

### 🔴 المشكلة الرئيسية: صوت سوروبانا لا يعمل

**ما تمت تجربته وفشل:**
1. ❌ **Web Speech API** (`window.speechSynthesis`) — Chrome Android يرفضه في التطبيقات المنشورة.
2. ❌ **Google Translate TTS** — يرفض الطلبات من التطبيق (Referer).
3. ❌ **Edge TTS** — لا يعمل على Chrome (قيود مايكروسوفت).
4. ❌ **ResponsiveVoice** — لا يقبل نطاقات GitHub Pages المجانية.

**الحل الذي نعمل عليه حالياً:**
- **ملفات MP3 محلية** داخل `public/audio/`.
- 11 ملف تم توليدها عبر TTSMaker (صوت نسائي سوري "نور").
- الملفات مرفوعة على: `https://mezo2021.github.io/sorobanmind-platform_2026/audio/`
- **المشكلة الآن:** الصوت لا يُشغَّل داخل التطبيق رغم أن الرابط يعمل مباشرة في المتصفح.

**ما تم التحقق منه:**
- ✅ الملفات مرفوعة بشكل صحيح.
- ✅ الروابط المباشرة تعمل (فتحت `greeting-1.mp3` وشُغّل).
- ❌ التطبيق لا يشغّلها عند الضغط على زر 🔊.
- ✅ زر الصوت يتغير لونه لحظة ثم يعود (يعني `play()` يُستدعى ويفشل).

**الملفات الصوتية الحالية:**

- التطبيق يعمل على: `/sorobanmind-platform_2026/`
